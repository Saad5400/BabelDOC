# Exact versions for every runtime dependency of the doctranslate image.
#
# server/Dockerfile installs with `-c server/constraints.txt`, so a rebuild
# gets these versions rather than whatever PyPI released since. Without it a
# fresh build resolved bitstring 5.0, which removed BitStream, and the job
# worker died on startup (see server/smoke_imports.py).
#
# These are the versions the server test suite passes on (Python 3.12,
# linux x86_64). To upgrade: change a pin (or regenerate with
#   uv pip compile pyproject.toml server/requirements.txt \
#     --python-version 3.12 --python-platform x86_64-unknown-linux-gnu \
#     --no-header --no-annotate -o server/constraints.txt
# after updating a venv), run `pytest server`, and build the image: the build
# runs the smoke test.
